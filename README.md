The LSTM model was evaluated using audio samples containing clear and noisy speech.
The evaluation included metrics such as:
Accuracy
Confusion Matrix
Word Error Rate (WER)
Character Error Rate (CER)
PESQ
STOI
Signal-to-Noise Ratio (SNR)
Results
After audio enhancement:
PESQ: improved from 2.85 to 4.05
STOI: improved from 0.82 to 0.93
SNR: improved from 7.49 dB to 18.47 dB
WER: decreased from 18.37% to 4.48%
CER: decreased from 11.51% to 3.51%
Final transcription accuracy: 95.52%
The usability evaluation also showed that users found the application easy to use, with a perceived ease-of-use mean of 4.07.
📊 Performance
The model performed well with clear and moderately noisy audio.
However, performance decreased when the input contained:
Strong background noise.
Different accents.
Unclear pronunciation.
The T5 model helped improve text readability and reduce transcription errors.

🌍 Social Impact
Afseh aims to make communication easier and more accessible for individuals with speech difficulties.
By combining Artificial Intelligence, speech recognition, text correction, and mobile technology, the project provides a practical solution for converting unclear speech into clearer text and audio.
